随机点名

v1.2

告别“今天该轮到谁了”，一键抽人，公平又热闹。

核心功能

  • 名单一次导入：把班级名单粘贴进去（一行一个名字），下次打开自动记住。
  • 滚动抽取动画：名字快速滚动后定格，全班注意力瞬间集中，课堂气氛拉满。
  • 不重复模式：抽过的同学自动跳过，全班轮完一遍才重新开始，谁也别想“逃”。
  • 可抽多人：一次抽取 1～6 人，小组任务、上台板演一次抽齐。
  • 大字投影：结果超大字显示，最后一排也能看清。
  • 记录与撤回：自动保存抽取记录，抽错了可以撤销重抽。

排座位工具

v1.0

换座位不用再拿纸笔反复涂改，几十秒生成一张新座位表。

核心功能

  • 自由设置座位布局：几行几列、是否留过道，按自己班的教室实际情况来。
  • 多种排座规则：随机打乱 / 按学号 / 按身高（矮的靠前），一键切换。
  • 固定座位：视力不好、需要坐前排的同学可锁定位置，重排时不受影响。
  • 邻座避让：把爱说话的同学设为“不同桌”，排座时自动错开。
  • 手动微调：生成结果后可拖动交换，个别调整不用重新排一遍。
  • 导出打印：座位表可导出为图片或表格，打印出来贴讲台、发班级群都方便。

HOW TO USE

三步就能用起来

1

下载压缩包

在上方点击对应工具的下载按钮，得到 随机点名1.2.zip 或 排座位工具1.0.zip。

2

解压到本地

右键选择“解压到当前文件夹”。建议解压到桌面或 D 盘，不要直接在压缩包里双击运行。

3

双击启动

打开解压后的文件夹，双击主程序即可。第一次使用先导入班级名单，之后每次打开都会自动加载。
