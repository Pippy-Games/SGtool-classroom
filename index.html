随机点名

v1.2

告别“今天该轮到谁了”，一键抽人，公平又热闹。

核心功能

  • 名单一次导入：把班级名单粘贴进去，下次打开自动记住。
  • 滚动抽取动画：名字快速滚动后定格，全班注意力瞬间集中。
  • 不重复模式：抽过的同学自动跳过，全班轮完一遍才重新开始。
  • 置顶显示：窗口始终置顶，不被其他软件挡住。
  • 语音播报：抽到名字时自动语音念出来（可开关）。
  • 状态统计：实时显示“已点 X · 剩余 Y · 共 Z 人”。
  • 一键重置：随时重新开始一轮，灵活控制课堂节奏。

排座位工具

v1.0

换座位不用再拿纸笔反复涂改，几十秒生成一张新座位表。

核心功能

  • 布局设置：自由调整小组数（如 6 组）和每组排数（如 8 排）。
  • 同桌设置：可让相邻两组同桌，或全部独立，灵活控制。
  • 讲台边飞机位：可设置讲台两侧的特殊座位数量。
  • 学生名单：支持导入、清空、示例，可随机打乱名单顺序。
  • 智能排座（推荐）：一键按规则自动生成座位表。
  • 按名单顺序排座：按导入顺序依次落座。
  • 导出 A4 横图 / 导出文本：座位表可打印、可存档。
  • 实时统计：总座位数、已用/空余座位一目了然。

HOW TO USE

三步就能用起来

1

下载压缩包

在上方点击对应工具的下载按钮，得到 随机点名1.2.zip 或 排座位工具1.0.zip。

2

解压到本地

右键选择“解压到当前文件夹”。建议解压到桌面或 D 盘，不要直接在压缩包里双击运行。

3

双击启动

打开解压后的文件夹，双击主程序即可。第一次使用先导入班级名单，之后每次打开都会自动加载。
